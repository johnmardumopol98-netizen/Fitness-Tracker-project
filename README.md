# Fitness Tracker

React Native + TypeScript + Expo fitness tracking application.

## Install
npm install

## Run
npx expo start

## Screens
Home, My Workouts, Add Workout, Workout Details, Edit Workout, Profile.

Features include React Navigation, Context state management, JSON parsing, CRUD, search, validation, Modal, Alert, ActivityIndicator, FlatList, ScrollView, Image, Pressable, TouchableOpacity, Button, TextInput, and SafeAreaView.
